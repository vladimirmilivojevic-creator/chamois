Pick a demo role

Both use public demo tokens. Researchers submit circuits and see their own jobs. Operators see the whole queue and edit the device calibration.

Circuits use AQT's native gates (R, RZ, RXX, MEASURE) in the ARNICA job format. A Rust scheduler turns them into a nanosecond-timed pulse timeline; a simulated 10-ion device runs it.
